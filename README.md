# Pavement Fatigue and Rutting Life Predictor

Gradio web application for the FEM surrogate model developed for prediction of flexible pavement fatigue life, rutting life, governing design life, and damage.

## Model workflow

The application predicts the critical pavement strains using the trained surrogate models and then applies the Asphalt Institute transfer functions to calculate:

- Tensile strain at the base of asphalt (`et_BCAC`)
- Vertical compressive strain at the subgrade (`ec_SGF`)
- Fatigue life (`Nf`)
- Rutting life (`Nr`)
- Governing design life (`N_design`)
- Damage ratio (`D`)
- Governing distress mode
- PASS / MARGINAL / FAIL verdict

## Deployment

This repository is designed for deployment as a Gradio application on Hugging Face Spaces.

### Required model file

Place the trained model bundle generated by the original notebook in the repository root:

```text
pavement_surrogate.joblib
```

The original notebook creates this bundle after refitting the two deployed strain models in log10 space.

## Run locally

```bash
pip install -r requirements.txt
python app.py
```
